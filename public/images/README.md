## Dicas de estilo

- Todas as imagens de seção (arquitetos, estrategistas, desenvolvedores) do PDF original usam robôs/figuras de IA com **tonalidade escura e acinzentada** — mantenha o mesmo visual.
- Para o mapa do ES, prefira uma versão **monocromática** ou com baixo contraste — o componente já aplica um `drop-shadow` verde.
- O background `espaco-criativo.jpg` será exibido com **opacidade 10%** — pode ser uma foto de sala de coworking ou evento de inovação.
- O logo `ecohos-logo.png` deve ter **fundo transparente** para funcionar bem sobre o fundo escuro.
